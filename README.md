## 📂 總覽頁

首頁以生活問題引導學習：

- **第一課入口**：買一送一，卻比較貴？第21條不實廣告，85秒動畫搭配互動講義。
- **六個問題主題**：不實廣告、聯合行為、轉售價格限制、獨占與限制競爭、不公平競爭、調查與賠償；尚未提供的主題標示「後續課程」。
- **所有教材**：依主題、案例或條號搜尋，並可按法規章節篩選。
- **依法條找教材**：收合式七章目錄，已有教材的章節可點選篩選。

## 每份教材包含

| 內容 | 說明 |
|---|---|
| 短影音 | 直式動畫，生活案例開場，台灣華語旁白與字幕 |
| 互動講義 | 條文原文逐句反白＋白話解釋、判斷流程、自我練習 |
| 來源 | 條文以全國法規資料庫現行條文為準；處分案、判決附字號與查詢路徑 |
